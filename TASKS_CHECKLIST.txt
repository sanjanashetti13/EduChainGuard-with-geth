SECTION C — LOCAL GETH (CHAIN ID 1337 — MATCHES THIS REPO)
================================================================================

IMPORTANT: Your lab PDF (Geth_SingleNode_setup_modified.pdf) uses chainId 4321.
This EduChainGuard repo is wired for CHAIN ID 1337 in:
  - blockchain\genesis.json
  - frontend MetaMask “Geth Local” (see frontend\src\utils\blockchain.js)

For this project, follow THIS repo’s 1337 genesis unless your teacher forces
4321 — if they force 4321, you must change genesis + frontend chain constants
together (ask your instructor which chain ID to submit).

C1. Pick a datadir (empty folder for blockchain data)
    Example:
      cd "...\EduChainGuard\blockchain"
      mkdir gethdata

C2. Initialize genesis (ONCE per fresh gethdata)
      geth --datadir .\gethdata init .\genesis.json

C3. Start Geth with HTTP RPC on 8545
    Example (adjust path to geth if not on PATH):

      geth --datadir .\gethdata --http --http.addr 127.0.0.1 --http.port 8545 ^
        --http.api eth,net,web3,personal --allow-insecure-unlock

    Notes:
    - Keep this terminal open while developing.
    - Newer Geth versions may deprecate “personal” API — if commands fail,
      check Geth release notes; you may need different flags or a miner setup.
    - For a private chain you often also use --nodiscover and a matching
      network id; for simplest class setup, matching genesis chainId 1337 is
      the priority so MetaMask + Truffle agree.

C4. Geth JavaScript console (optional, for class-style steps)
    Attach (syntax varies by Geth version), e.g.:
      geth attach http://127.0.0.1:8545
    In console you can:
      personal.newAccount("yourPassword")
      eth.accounts
    Keystore files are stored under:
      <datadir>\keystore\
    Example:  blockchain\gethdata\keystore\UTC--...json

C5. Funding accounts for gas (local)
    You need ETH on the account that will:
    - Deploy via Truffle (migrate uses a Geth account / coinbase), OR
    - Sign txs from MetaMask on “Geth Local”.
    If your chain does not auto-mine, configure mining per your lab PDF
    (miner.start) OR use a Geth version / flags your course provides.

C6. MetaMask: network “Geth Local”
    The app’s Admin navbar has buttons to add/switch networks.
    Manual add if needed:
      Network name:     Geth Local
      RPC URL:          http://127.0.0.1:8545
      Chain ID:         1337
      Currency symbol:  ETH

C7. Import / use an account
    - MetaMask: create a new account OR import (see course rules: keystore vs
      private key). Fund that account from a Geth account with balance.

SECTION J — TROUBLESHOOTING (COMMON ISSUES)
================================================================================

J1. “Set REACT_APP_CONTRACT_ADDRESS_LOCAL” error
    → .env.local missing or wrong name; restart npm start.

J2. MetaMask wrong chain
    → Use navbar “Geth Local” or manually add network chain 1337.

J3. Truffle migrate fails / no account
    → Geth not running, wrong port, or no unlocked/funded deployer account.

J4. Flask “Web3 is not connected to Polygon Amoy”
    → RPC down or wrong .env; fix Amoy RPC / keys.

J5. CORS errors
    → Flask already uses CORS(app); ensure frontend URL/port matches.

J6. Institute upload rejects file
    → Backend allows .pdf for /institute/upload; use PDF for that route.
